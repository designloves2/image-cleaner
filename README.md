# Image Cleaner

완전히 같은 이미지는 **하나만 남기고**, 하위 폴더에 흩어진 이미지를 **한곳으로 병합·연도별 정리**해 주는 Windows 네이티브 이미지 관리 프로그램입니다.
Rust로 작성되어 런타임/DLL 없이 `.exe` 하나로 동작합니다.

## 주요 기능

**정리**
- 원본 폴더의 모든 하위 폴더를 스캔 → 내용이 **바이트 단위로 동일한** 이미지(BLAKE3 해시)만 중복으로 판정해 하나만 보존
- 파일명은 같지만 내용이 다르면 **두 파일 모두** 원본 폴더명을 접미사로 붙여 구분 (`IMG_001_여행.jpg`, `IMG_001_가족.jpg`) — 번호 괄호를 쓰지 않아 연속성이 유지됨. 폴더명까지 같으면 상위 폴더명을 더 붙임
- 옵션: **모든 파일명에 원본 폴더명** 붙이기 (여러 하위 폴더를 합칠 때)
- 폴더명 위치 선택: **뒤(접미사)** `IMG_001_여행.jpg` / **앞(접두어)** `여행_IMG_001.jpg` — 날짜 폴더는 앞에 두면 정렬이 잘 됨
- 옵션: **촬영(생성) 연도별 폴더** 분류 — EXIF 촬영일 → 파일 생성/수정일 순으로 판단
- **원본 유지** 또는 **원본 삭제(앱 내 휴지통 보관)** 선택
- **미리 분석**: 파일을 건드리지 않고 결과(중복·이름 변경·연도별 분포)를 먼저 확인
- 처리 화면: 단계 표시기, 진행 링, 실시간 카운터, 처리 속도 그래프, 남은 시간
- 완료 후 **결과 리포트 창**(요약 / 중복 목록 / 이름 변경 목록, CSV 저장)
- 폴더 트리에서 우클릭 → **현재 폴더 정리하기** → 결과 폴더만 정하면 바로 시작

**이미지 관리**
- 좌측 폴더 트리 + 우측 작업 영역(썸네일 카드 그리드), 정렬·검색·썸네일 크기 조절·하위 폴더 포함
- 미리보기 / 전체화면 뷰어(확대·이동·이전/다음), 파일 상세 정보와 EXIF
- 다중 선택, 이름 변경, 해시 계산, 탐색기에서 보기, 경로 복사
- **앱 내 휴지통**: 삭제한 파일을 보관 → 복원 / 다른 위치로 복원 / 영구 삭제 / 비우기
  - 복원 충돌 처리: 같은 이름의 **동일 파일**이 이미 있으면 휴지통에서만 제거, **다른 파일**이면 덮어쓰지 않고 `이름_복원.jpg` 로 복원, 원래 드라이브/폴더를 쓸 수 없으면 `사진\Image Cleaner 복원` 으로 대체
  - 다른 위치로 복원 시 같은 이름의 폴더(`A\여행`, `B\여행`)는 상위 폴더명을 붙여 `A_여행`, `B_여행` 으로 구분
- 라이트 · 다크 테마 (flat 디자인), 폴더 끌어다 놓기

## 설치

[Releases](https://github.com/designloves2/image-cleaner/releases) 에서 `ImageCleaner-Setup-<버전>.exe` 를 내려받아 실행하세요.
기본적으로 사용자 단위로 설치되어 관리자 권한이 필요 없습니다.

### 자동 업데이트
앱이 시작될 때 GitHub Releases 의 최신 버전을 확인하고, 새 버전이 있으면 설치 파일을 내려받아
**SHA-256 체크섬을 검증**한 뒤 "지금 재시작하여 설치" 로 업데이트합니다. (정보 ⓘ 창에서 끄거나 수동 확인 가능)
조회하는 것은 공개 릴리스 정보뿐이며 사용자 정보는 전송하지 않습니다.

## 빌드

요구 사항: Rust(stable, MSVC 툴체인), (설치 파일 생성 시) [Inno Setup 6](https://jrsoftware.org/isinfo.php)

```powershell
cargo run --release              # 실행
cargo test --release             # 테스트
./installer/build.ps1            # dist\ImageCleaner-Setup-<버전>.exe 생성
```

## 릴리스(배포) 방법

1. `Cargo.toml` 의 `version` 을 올리고 커밋
2. 태그를 푸시: `git tag v1.0.1 && git push origin v1.0.1`
3. GitHub Actions(`release.yml`)가 테스트 → 설치 파일 빌드 → Release 게시까지 자동 수행
4. 이미 설치된 앱들이 다음 실행 때 자동으로 업데이트를 안내/다운로드합니다.
